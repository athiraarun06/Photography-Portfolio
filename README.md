#  Photography Portfolio Website

## Web Technology Laboratory Project

This Photography Portfolio Website was developed as part of the **Web Technology Laboratory** course. The project demonstrates the use of fundamental HTML5 elements, semantic tags, hyperlinks, tables, lists, images, and basic CSS styling to create a simple portfolio website.

---

##  Project Description

The website showcases a beginner-friendly photography portfolio with a clean layout and a light pink theme. It includes a photo gallery, photography projects, photography terms, equipment lists, and contact information while demonstrating proper HTML5 structure and formatting techniques.

---

##  Features

- HTML5 Semantic Elements
- Internal CSS Styling
- Light Pink Theme
- Photo Gallery with Clickable Images
- Photography Projects Table
- Description List
- Ordered Nested List
- Unordered Nested List
- Internal Navigation Links
- External Hyperlink
- Bookmark Link
- Email Link (`mailto:`)
- Phone Link (`tel:`)
- Responsive and Beginner-Friendly Design

##  Technologies Used

- CSS (Internal Styling)
